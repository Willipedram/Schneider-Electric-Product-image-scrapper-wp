# Schneider Model Code Extractor

## نصب
1. تنها پوشه‌ی `schneider-model-code-extractor` را فشرده‌سازی کنید (نه کل مخزن را).
2. فایل zip تولید شده را در «افزودن افزونه» وردپرس بارگذاری کنید.
3. پس از فعال‌سازی، از منوی «Model Code Extractor» در پیشخوان برای اجرای استخراج استفاده کنید.

## نیازمندی‌ها
- وردپرس 5.8 به بالا
- PHP 7.4 به بالا
- افزونه ووکامرس فعال
